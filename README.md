# Постановка лодки

Веб-приложение для телефона (iOS и Android). Считает, сколько нажатий GPS-якоря нужно, чтобы рыба, найденная эхолотом, оказалась **за кормой на 12 часов** на заданном расстоянии. Устанавливается иконкой на экран и после первого открытия работает без интернета (PWA).

## Запуск на компьютере

```bash
python3 tools/serve.py           # http://localhost:8080
python3 tools/serve.py --lan     # плюс доступ с телефона по Wi‑Fi: http://<IP компьютера>:8080
```

С телефона по Wi‑Fi (http по IP-адресу) приложение откроется и будет считать. Но режим без интернета браузеры включают только на **https** или **localhost**, поэтому полностью он проверяется уже на хостинге.

## Как пользоваться

1. **Где рыба** — вид сверху: в центре датчик, кольца через 5 м до 30 м. Тап по месту ставит сразу часы и расстояние. Тап по цифре часов меняет только направление. Тап округляет до получаса и 1 м, а если вести пальцем — шаг 10 минут. Кнопки −/+ под схемой подправляют часы (по 10 минут) и метры (по 1 м).
2. **Спуск лески** — на каком расстоянии от кормы должна оказаться рыба: от 1 до 30 м, ползунком или −/+. Значение запоминается, на схеме это зелёная точка на линии 12 часов.
3. Вверху показано, сколько нажатий сделать **вперёд/назад** и **влево/вправо**. Кнопки якоря считаются от носа лодки.

## Система отсчёта и расчёт

Человек сидит у кормы и смотрит за корму: **12 ч — за кормой, 6 ч — нос, 3 ч — справа от него** (это левый борт, если смотреть от носа).

```
θ        = часы × 30° + поворот датчика
за кормой = D·cos θ − (датчик ближе к носу, м)
вправо    = D·sin θ                    (вправо для сидящего у кормы)

вдоль  = за кормой − желаемое   → >0: НАЗАД,  <0: ВПЕРЁД
вбок   = вправо                 → >0: ВЛЕВО (по носу), <0: ВПРАВО
нажатия = round(|сдвиг| / шаг), шаг: 1 м вдоль, 1,5 м вбок (настраивается)
```

Лодка двигается по прямым и сохраняет курс, рыба неподвижна. Нажатия только целые, поэтому остаётся промах до половины шага по каждой оси. Приложение показывает, на сколько часов и метров рыба окажется после перестановки.

**Допущения (меняются в «Настройках»):** часы вводятся относительно лодки (поворот датчика 0°), датчик у кормы (0 м), течение идёт вдоль корпуса, и наживка уходит на 12 часов.

## Файлы

| Путь | Что это |
|---|---|
| `app/` | **Сам сайт.** Для хостинга выкладывается целиком эта папка |
| `app/calc.js` | Формулы (без интерфейса) |
| `app/app.js`, `index.html`, `styles.css` | Интерфейс |
| `app/sw.js` | Работа без интернета (кэш приложения) |
| `app/manifest.webmanifest`, `app/icons/` | Установка на экран, иконки |
| `tests/calc.test.mjs` | Проверки формул: `node --test tests/calc.test.mjs` |
| `tools/serve.py` | Локальный сервер |
| `tools/make_icons.py` | Перерисовать иконки: `python3 tools/make_icons.py` |

## Хостинг

Приложение опубликовано на GitHub Pages: **https://scraller.github.io/boat-positioning/**

Каждый push в ветку `main` запускает [.github/workflows/pages.yml](.github/workflows/pages.yml): сначала проверяются формулы, потом на сайт выкладывается папка `app/`. Если тесты не прошли, сайт не обновится.

**При каждом изменении файлов приложения** увеличьте `VERSION` в `app/sw.js` и `app/app.js`. Телефоны получат обновление при следующем открытии с интернетом: страница один раз перезагрузится сама.
