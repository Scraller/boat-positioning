Настройки якоря и датчика

0 — часы вводятся сразу относительно лодки. Если берёте направление с экрана эхолота, а датчик повёрнут, укажите его поворот: по часовой «+», против «−». 30° = 1 час.

0 — датчик у кормы. Расстояние «до рыбы сейчас» берётся с эхолота, по горизонтали.

Установить на телефон

iPhone: откройте в Safari → кнопка «Поделиться» → «На экран „Домой“».

Android: откройте в Chrome → меню ⋮ → «Установить приложение» или «Добавить на главный экран».

После первого открытия приложение работает без интернета.
